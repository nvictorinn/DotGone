# DotGone

DotGone automatically removes the hidden files macOS leaves on USB sticks and FAT32 or exFAT drives — `._*`, `.DS_Store` and friends — so your drives stay clean on Windows, Linux, cameras and TVs.

- Cleans on mount, continuously while a drive is plugged in, and right before you eject it.
- Never touches macOS drives (APFS, HFS+).
- Can stop macOS from creating `.DS_Store` files, Spotlight indexes and the fseventsd log.
- Lives in the menu bar, in 23 languages, and updates itself.

## Download

**[Download DotGone](https://github.com/nvictorinn/DotGone/releases/latest/download/DotGone.dmg)** — requires macOS 26.2 or later.

Open the disk image and double-click DotGone: it moves itself to Applications, replacing an older copy if there is one. DotGone is signed with a Developer ID and notarized by Apple.
